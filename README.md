# Loading...

> Fórum e acervo de todos os jogos: do Atari ao PlayStation 5, do DOS à Steam. Sem anúncios, sem rastreadores.

## Sobre o Projeto
O **Loading...** é uma enciclopédia aberta e fórum comunitário focado em clareza, velocidade e dados de jogos.

### Funcionalidades
- **Acervo de Jogos:** Catálogo com visualização fluida em tela cheia, informações de plataformas, desenvolvedoras, gêneros e notas do Metacritic.
- **Preview Dinâmico (Hover):** Transição suave revelando capturas de gameplay em alta resolução ao passar o cursor sobre as capas.
- **Filtros por Plataforma:** Navegação rápida por PC, PlayStation, Xbox, Nintendo e Retrô.
- **Fórum Comunitário:** Discussões integradas por jogo, salvamento local e suporte a respostas encadeadas.
- **Modos de Tema:** Suporte automático e alternador para temas Claro, Escuro e Auto no cabeçalho.
- **Integração com API RAWG:** Suporte a chave de API para expandir a biblioteca para mais de 500 mil títulos.

## Como Executar
Basta abrir o arquivo `index.html` em qualquer navegador web moderno.
